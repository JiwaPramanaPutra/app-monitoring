# Frontend (Angular)

Aplikasi Angular untuk Nadi. Setup, konfigurasi, dan cara menjalankan
didokumentasikan di [README utama](../README.md).

Perintah cepat:

- `npm start` — dev server di http://localhost:4200 (proxy `/api` ke backend `:3000`)
- `npm run build` — build produksi ke `dist/frontend`
- `npm test` — unit test (Vitest)
